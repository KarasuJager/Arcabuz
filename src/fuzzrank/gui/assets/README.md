# Approved artwork

`fuzzrank-logo.png` is a byte-for-byte copy of the owner's approved image in
`docs/assets/fuzzrank-logo.png`. It is packaged as an application resource.

The GUI displays a viewport onto the helmet/chart region for its compact badge and
window icon. `gui/brand.py` records that region relative to the original 1448×1086
composition and scales it for native icon sizes. No new mark or replacement pixels
are generated, and the approved original is unchanged. The original dark navy background
is intentionally retained in both themes. No transparent variant or standalone installer
icon is claimed. The approved original artwork remains unchanged.
